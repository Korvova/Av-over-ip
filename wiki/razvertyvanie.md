## Установка на новый мини-ПК

Ubuntu 22.04 или 24.04, затем одна команда:

```
git clone https://github.com/Korvova/Av-over-ip.git /opt/ekoder
sudo bash /opt/ekoder/deploy/install-ubuntu.sh
```

Скрипт ставит Node.js 22 и PostgreSQL, создаёт базу, применяет миграции, собирает
интерфейс и регистрирует службу `ekoder` с автозапуском. По окончании печатает адрес
веб-интерфейса.

Полезные команды:

```
systemctl status ekoder      состояние службы
journalctl -u ekoder -f      живой журнал
systemctl restart ekoder     перезапуск
```

## Сетевые порты

У мини-ПК два Ethernet-порта, оба настроены статикой (профили NetworkManager
`upravlenie` и `video-lan`, автоподключение включено, посторонние профили удалены).
Так порт всегда поднимается с нужным адресом сам — без DHCP и ручных действий.

| Порт | Профиль | Адрес | Назначение |
|---|---|---|---|
| enp45s0 (первый) | upravlenie | 192.168.1.20/24 | сеть управления, доступ к веб-интерфейсу |
| enp46s0 (второй) | video-lan | 169.254.99.20/16 | видео-сеть, коммутатор с энкодерами |

Запасной профиль `internet` на втором порту получает адрес по DHCP — включается
через меню сети, когда мини-ПК нужен интернет (например, для обновления).

**Важно при выезде на объект.** Если энкодеры на объекте живут в другой подсети
(скажем, 192.168.5.x), адрес видео-порта нужно поменять под их сеть, иначе платформа
физически не увидит устройства:

```
sudo nmcli con mod video-lan ipv4.addresses 192.168.5.20/24
sudo nmcli con up video-lan
```

## Обновление

Страница «Настройка платформы управления» → **Проверить обновления** →
**Обновить из GitHub**. Платформа скачает свежую версию, поставит зависимости,
пересоберёт интерфейс, применит миграции базы и перезапустится. Номер сборки там же —
это число коммитов в репозитории, растёт само.

Требуется интернет на мини-ПК. Без интернета — вручную:

```
cd /opt/ekoder && sudo bash deploy/update.sh && sudo systemctl restart ekoder
```

Обновление откажется работать, если в рабочей копии есть незакоммиченные изменения —
защита от затирания правок на машине разработчика.

## Если устройства не находятся

1. **Проверить подсеть.** IP устройства видно на его передней панели: удерживать
   кнопку UP пять секунд, адрес прокрутится на табло. Он должен быть в той же сети,
   что и видео-порт мини-ПК.
2. **Добавить вручную.** Страница «Элементы системы» → поле **Добавить по IP-адресу**.
   Достаточно адреса одного любого устройства — через него платформа опросит
   и найдёт всю остальную сеть.
3. **Посмотреть, кого видит сам мини-ПК:**

```
ip -br a       свои адреса на портах
ip neigh       соседи, замеченные в сети
```
