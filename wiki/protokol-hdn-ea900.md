Устройства HDN-EA900 построены на чипах ASPEED AST1530/1535. Документация лежит
в репозитории: выжимки из вендорских файлов — папка `_docs/`, полный комплект
производителя — «Full API for JPEG2000».

## Подключение

**Telnet, порт 24** (не 23!), логин `root`, пароль `17909`. У чистых плат ASPEED
пароль не запрашивается — драйвер обрабатывает оба случая.

Два вида команд:

* `astparam s <ключ> <значение>` — сохраняется во флеш, требует `astparam save`
  и перезагрузки устройства;
* `e e_<команда>::аргументы` — выполняется сразу, без перезагрузки.

## Коммутация

Работает через каналы вещания: у каждого энкодера свой номер канала от 0000 до 9999,
декодер подключается к нужному каналу.

```
энкодеру:   e e_reconnect::0001              назначить канал и запустить вещание
декодеру:   e e_reconnect::0001::v           подключить видео к каналу 0001
            e e_reconnect::0001::a           аудио; u — USB, r — ИК, s — RS-232, c — CEC
            e e_stop_link::v                 отключить сигнал
```

Платформа назначает энкодеру канал, равный его ID в системе. Чтобы один источник
шёл на несколько экранов, нужен многоадресный режим: `astparam s multicast_on y`
с перезагрузкой устройства.

## Поиск устройств

Штатный механизм — команда `node_query --dump --json`, которую запускают **на самом
устройстве**: оно опрашивает всю сеть и возвращает список — MAC, IP, роль
(энкодер/декодер), канал, состояние.

Отсюда логика платформы: чтобы найти всю сеть, достаточно достучаться до одного
устройства. Кандидатов ищем по порядку — известные адреса из базы, mDNS-анонсы
(устройства называют себя `ast*`), таблица соседей операционной системы. Если ничего
не нашлось, администратор вводит адрес одного устройства руками.

## Видеостены

API версии 2: каждой панели задаётся вырез из общего кадра в десятитысячных долях.

```
e e_vw_enable_{X1}_{Y1}_{X2}_{Y2}_2      координаты 0..10000
e e_vw_enable_0_0_0_0_2                  выйти из режима стены (полный кадр)
e e_vw_rotate_3                          поворот 180°, _6 — 270°
```

Компенсация рамок считается из размеров панели: внешняя ширина и высота против
видимой области. Платформа хранит их в настройках стены и пересчитывает координаты
сама.

## Живая картинка

`http://<ip>:8080/?action=stream` — поток MJPEG, `?action=snapshot` — один кадр.
До 1280×720 и 30 кадров в секунду, около 8 Мбит/с. Платформа проксирует эти адреса
через себя, чтобы браузер оператора из сети управления видел картинку из видео-сети.

## Сетевые настройки устройств

Задаются не по Telnet, а пакетом на групповой адрес `225.3.0.0:3335`: пять полей
по 20 байт — MAC без разделителей, режим (`static`/`dhcp`), адрес, маска, шлюз.
Устройство сверяет MAC, применяет настройки и перезагружается само.

## Что стоит помнить

* Заводской сброс: удерживать кнопку RESET пять секунд.
* Обновление прошивки в объём проекта не входит (решение заказчика).
* Часть параметров ТЗ (чётность и скорость RS-232, нормальное состояние реле,
  поворот изображения, отображение ID) сохраняется в базе платформы, но команд
  их применения в документации ASPEED нет.
